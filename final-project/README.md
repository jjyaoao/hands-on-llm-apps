## 正式提交

学习通期末考试采用限时提交。请提前完成项目，准备好 `学号_期末综合项目.pdf` 和 `学号_期末综合项目源码.zip`。待窗口开放后，再进入学习通考试入口上传两份附件。开放时间和截止时间将另行通知。有问题可在课程答疑群提问。
