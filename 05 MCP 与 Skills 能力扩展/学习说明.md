# 05 MCP 与 Skills 能力扩展

先阅读 `课件/` 中的 PDF，再按 05A～05C 的顺序打开 `Notebook/`。

| 实践 | 内容 | 运行条件 |
| --- | --- | --- |
| [05A](Notebook/01-mcp-tools.ipynb) | 跨进程连接 MCP 工具并生成能力审计 | 安装本节 `requirements.txt`；本地 stdio，无需联网 |
| [05B](Notebook/02-skill-discovery.ipynb) | 发现、激活并按需读取示例 Agent Skill | 安装本节 `requirements.txt`；读取 `代码/skills/repo-guide/` |

从资料根目录启动 JupyterLab。先安装 [本节依赖](requirements.txt)，再按顺序运行 Notebook；MCP 会启动随课的只读服务端子进程。`代码/` 放课程源码、自检和示例 Skill，实践还会读取第 2 节 `数据/demo-repo/` 中的自编示例仓库，因此请保留整个资料库的目录结构。

05C 默认 `RUN_LIVE = False`，不会发起收费请求。只有自行配置密钥、确认费用并将开关改为 `True` 才会调用模型。`数据/实验记录/` 是课程制作时的历史观测输入，已移除完整对话消息；保存的结果不代表当前服务会给出相同回答。练习先独立完成，再展开 Notebook 中的参考分析。
