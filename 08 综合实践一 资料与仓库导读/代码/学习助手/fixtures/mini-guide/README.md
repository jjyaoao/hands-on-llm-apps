# Mini Guide：可解释的小检索器

这个自编仓库演示“问题 -> 检索 -> 证据”的学习过程，不含在线模型。

1. 先读 `search.py`，理解关键词如何变成分数。
2. 再读 `main.py`，观察 top_k 如何影响输出条数。
3. 最后读 `learning-notes.pdf`，比较命中资料与回答正确。

`search` 对关键词做小写转换，按包含的查询词数打分，忽略零分条目。
相同得分保持原资料顺序。它没有语义编码，也不把相似度解释成正确概率。

练习：把 top_k 改为 1，先预测再运行本仓库 main.py。课程助手只读取这些文件，不擅自执行导入的仓库代码。
