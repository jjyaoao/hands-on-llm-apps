# 08 综合实践一 资料与仓库导读

先看 `课件/` 中的 PDF，再按 08A～08C 的顺序打开 `Notebook/`。

| 实践 | 内容 | 运行条件 |
| --- | --- | --- |
| [08A](Notebook/01-source-map.ipynb) | 为 PDF 和小型代码仓库建立资料地图、检索与回查坐标 | 安装本节依赖；使用随课自编 Mini Guide；无需联网 |
| [08B](Notebook/02-guided-learning.ipynb) | 运行可恢复的导读流程，审阅历史模型回答与引用 | 保留第 3、5、6 节目录；安装本节依赖；无需模型请求 |
| [08C](Notebook/03-hello-agents-input.ipynb) | 核对固定版本的跨仓库输入、补证记录与停止分支 | 默认只读来源清单和历史记录；下载第三方原文需自行显式开启 |

本节把自编 Mini Guide 作为可直接离线复现的输入。课件展示的《第一章 初识智能体》PDF 是课堂案例的第三方学习材料，未随 GitHub 仓库分发；这里的 Notebook 不依赖它，学生也可改用自己有权使用的 PDF。`代码/学习助手/` 包含本节必需的导入器、运行环境、只读资料服务、教学回放、自检和自编样例。第 9 节将在此基础上继续增加练习反馈。

先从资料库根目录安装第 5 节依赖，再安装[本节依赖](requirements.txt)。从资料库根目录启动 JupyterLab，运行结果写到 `.local/student-runs/l08/`。Mini Guide PDF 和源码为课程自编，可离线使用。`数据/hello-agents-input.json` 只记录固定提交与文件哈希；第三方原文不在本仓库。08C 的 `DOWNLOAD_REFERENCE = False` 保持默认关闭。

`代码/学习助手/results/` 中的三份 JSON 是课程制作时真实模型运行的离线观测输入，保留了回答、必要的工具读回证据和引用位置，已去掉完整对话与无关状态。这些回答需要回到原文复核，不是标准答案，也不表示当前模型会给出相同结果。默认运行三本 Notebook 不会发起模型请求；`study_cli.py` 只有显式指定 `--mode deepseek` 才尝试真实模型调用，请先了解费用与资料发送范围，密钥仅放本机环境变量。
