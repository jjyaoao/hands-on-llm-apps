# 07 智能体评估与对照实验

先看 `课件/` 中的 PDF，再按 07A～07C 的顺序打开 `Notebook/`。

| 实践 | 内容 | 运行条件 |
| --- | --- | --- |
| [07A](Notebook/01-tasks-and-graders.ipynb) | 定义任务契约，检查规则评分与模型评分的覆盖范围 | 读取本节开发集和历史评分记录；无需联网 |
| [07B](Notebook/02-metrics-and-benchmarks.ipynb) | 计算任务等权汇总、pass@k 与 pass^k | 本节历史试验记录；Python 标准库 |
| [07C](Notebook/03-controlled-comparison.ipynb) | 配对比较两种提示，保留格式失败与不确定性 | 安装本节 `requirements.txt` 中的 SciPy；无需模型请求 |

从资料根目录启动 JupyterLab，并保留第 2、5、6 节及本节的目录。先按首页说明安装第 5、6 节依赖，再安装[本节依赖](requirements.txt)。`代码/` 包含评分函数、自检及显式启动的真实模型重跑脚本；Notebook 把新的离线分析写入根目录 `.local/student-runs/l07/`。

`数据/tasks.json` 和 `数据/judge-cases.json` 是公开的教学开发集输入，含规则评分所需的预期值。`数据/实验记录/` 是课程制作时的 16 次真实试验与 3 个模型评分样例，经整理后只保留本节离线分析需要的最终回答、工具证据、用量、评分和任务摘要；完整模型消息和无关工作状态已移除。评分样例中的参考标签是课程编写时的教学预期，未经过第二位审阅者独立复核，不是人工金标。历史结果也不能代表当前模型的表现。

默认打开和运行三本 Notebook 不会发起收费请求。`run_evaluation.py`、`run_judge.py` 只有在命令行显式传入 `--live` 并配置自己的 `DEEPSEEK_API_KEY` 时才尝试真实模型调用；先确认账号可用模型、服务费用与资料发送范围。新结果写入 `.local/student-runs/l07/`，不会覆盖随课历史记录。
