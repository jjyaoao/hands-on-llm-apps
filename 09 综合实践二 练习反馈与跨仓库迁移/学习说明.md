# 09 综合实践二 练习反馈与跨仓库迁移

先看 `课件/` 中的 PDF，再按 09A～09C 的顺序打开 `Notebook/`。

| 实践 | 内容 | 运行条件 |
| --- | --- | --- |
| [09A](Notebook/01-exercise-feedback.ipynb) | 写小练习契约，运行起始尝试，检查修订后的边界用例 | 保留第 8 节项目目录；运行随课自编可信代码；无需联网 |
| [09B](Notebook/02-hints-and-memory.ipynb) | 验证分层提示、请求幂等、学习状态与历史模型反馈 | 安装本节 Pydantic；读取去敏历史记录；无需模型请求 |
| [09C](Notebook/03-transfer-and-review.ipynb) | 跨进程继续，迁移到第二个小仓库并做区分性回归 | 保留第 8 节 Mini Guide 与 Flashcards；无需联网 |

第 8 节的 `代码/学习助手/` 提供资料导入和运行环境。本节 `代码/学习反馈/` 只加入练习执行器、学习记录、反馈运行环境和两道课程自编小练习。`student.py` 是供对照的初稿；`teaching_revision.py` 是课内展示“修改后重新验收”的教学修订示例，不是平台上期末综合作业的参考答案。运行这些文件会执行课程随附的本地 Python 代码，执行器不是安全沙箱，请勿传入不信任的下载脚本。

从资料库根目录先安装第 5、8 节依赖，再安装[本节依赖](requirements.txt)，并从资料库根目录启动 JupyterLab。三本 Notebook 默认离线运行，新生成的审计记录写到 `.local/student-runs/l09/`。`代码/学习反馈/results/` 中两份 JSON 是课程制作时真实模型调用的历史观测输入，只保留本节离线分析需要的程序尝试证据、模型回答与工具返回；完整对话、教师审阅记录和无关工作状态未随学生版分发。历史模型输出不能代表当前服务状态，也不能替代程序实测。

正式的期末综合作业要求、评分和提交方式以教学平台发布内容为准，本仓库只提供可分离的正课实验材料。本节 PDF 已去除正式作业评分页。默认运行 Notebook 不会调用收费模型。
